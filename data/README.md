| file | content | origin |
|---|---|---|
| `npn4/npn4_opt_aig.csv` | the 222 NPN classes of 4-input functions with their exact AIG size (`opt_aig`) | third party, MIT; provenance and notice in `npn4/LICENSE-npn4_opt_aig.txt` |
| `npn4/npn4_xag.csv` | the same 222 classes with `opt_aig` and the exact XAG size `opt_xag`, computed with `certlab.encoders.xag` | this project |
| `npn4/npn4_mig.csv` | the same 222 classes with `opt_aig` and the exact MIG size `opt_mig`, computed with `certlab.encoders.mig`; a replication of the published MIG catalogue (DATE 2016, Table I) | this project |
| `manifest.csv` | the certification legs of the n = 5 forced-reconvergence witnesses, with the sha256 prefix (16 hex digits) of every pinned CNF and the command that regenerates it | this project |
| `witness/tree_chain_n5*.csv` | per-leg CNF and DRAT hashes of the tree lower-bound chains (formula mode, k = 1..8) of the four n = 5 witnesses | this project |

Truth tables are hexadecimal integers: bit `t` is `f(row t)`, and input `x_j` is bit `j-1` of `t`.

`manifest.csv` is what `tests/test_encoder_regression.py` checks: every pinned CNF must be
regenerated by the encoders byte for byte. A CNF hash is a property of the encoder alone and is
machine-independent; a DRAT proof's bytes depend on the solver build, so proofs are checked by
`drat-trim`, not by hash.
